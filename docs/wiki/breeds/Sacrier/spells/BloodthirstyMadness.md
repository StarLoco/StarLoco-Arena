# Bloodthirsty Madness

This is a life stealing spell which only can be used against allies.

| Field | Value |
|---|---|
| **Class** | Sacrier |
| **Cost** | 200K |
| **AP** | 2 |
| **Target** | Non-Self |
| **Range** | 1 to 1 |
| **Recast** | Yes |
| **Effect** | Steals 10 (Air) dmg |

**Notes**

- Only works against allies and friendly summons.
- Can be boosted as normal spells.
- See sram spell Life Theft for more information about life stealing.
