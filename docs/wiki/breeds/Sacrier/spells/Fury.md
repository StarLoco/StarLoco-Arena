# Fury

## Fury

This is a damage spell which also increases damage of caster.

| Field | Value |
|---|---|
| Class | Sacrier |
| Cost | 250K |
| AP | 3 |
| Target | Enemy |
| Range | 1 to 1 |
| Duration | 1 Round |
| Recast | Yes |
| Effect | 4 (air) dmg, +2 dmg of all elements |
| Critical Effect | 8 (air) dmg, +3 dmg of all elements |

**Notes**: Even if not hitting a target, the sacrier will still get the +2 dmg boost.

- Normally, Fury will, without any boosts and 6 AP, do 10 dmg.
- If the sacrier cast Fury two times each turn, he will do 14 dmg.
- See the Damage page for a comparison chart of all damage spells.
