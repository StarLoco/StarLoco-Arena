# Assault

This is a damage spell which also makes caster and target switch position.

| Field | Value |
|---|---|
| **Class** | Sacrier |
| **Cost** | 200K |
| **AP** | 3 |
| **Target** | Enemy |
| **Range** | 1 to 2 in Line |
| **Recast** | Yes |
| **Effect** | 7 (Air) dmg, switches with target |
| **Critical Effect** | 10 (Air) dmg, switches with target |

**Notes**

- If cast twice against same target you will hit more since when switching with target you will end up behind the enemy and thereby hitting his back.
- A nice trick is to walk to a killer tile or a tile that is about to be dropped, and then cast assault on an enemy.
- If assaulting a character that somebody has sacrified, the assault switch happen first, then the sacrifice switch.
- See the Damage page for a comparison chart of all damage spells.
