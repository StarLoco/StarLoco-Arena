# Attraction

This spell attracts target towards caster.

| Field | Value |
|---|---|
| **Class** | Sacrier |
| **Cost** | 200K |
| **AP** | 4 |
| **Target** | Any |
| **Range** | 1 to 7 in Line |
| **Recast** | Yes |
| **Effect** | Attracts target 3 tiles |
| **Critical Effect** | Attracts target 5 tiles |

**Notes**

- Attracting someone into an obstacle hurts the target. The amount inflicted depends on how many tiles the target is attracted before hitting the wall. The exact amount can be found on the Damage page (Push damage section).
