# Transposition

This spell makes caster and target swap positions.

**Class**: Sacrier
**Cost**: 200K
**AP**: 3
**Target**: Non-Self
**Range**: 1 to 5
**Recast**: Yes
**Effect**: Swaps position with target

---

**Notes**
- It is only possible to swap with allies and friendly summons.
- As of Beta 13, this has line of sight.
