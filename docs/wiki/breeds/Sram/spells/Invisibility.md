# Invisibility

This buff gives caster invisibility for 3 Rounds.

| Field | Value |
|---|---|
| Class | Sram |
| Cost | 200K |
| AP | 4 |
| Target | Self |
| Duration | 3 Rounds |
| Recast | No |
| Effect | Invisibility |

**Notes**: As invisible you can still be target of spells and weapons and you will still be affected by dodge rolls etc.

- Casting spells or being hit by spells does not dispel invisibility.
- You cannot see an invisible hostile character but you can often find out where he is located:
  1. When casting a spell on an empty tile where you suspect there is an invisible character you will see the effect of the spell in the fight history.
  2. If moving multiple tiles and suddenly get stopped in mid track, you can be sure there are an invisible character nearby.
  3. Moving into an invisible character will be treated as a failed move.
