# Diversion

This spell turns all nearby characters towards target tile.

| Field | Value |
|---|---|
| **Class** | Sram |
| **Cost** | 150K |
| **AP** | 2 |
| **Target** | Any |
| **Range** | 1 to 8 |
| **Recast** | Yes |
| **Effect** | Turns characters against impact |

**Notes**
- Is used to hit enemies in the back which yields 6 extra damage per hit. Hitting from the side yields 2 extra damage. See [this page](../../../mechanics/Damage.md) for more information about which spells is boosted from hitting from behind.
- This spell ignores [line of sight](../../../mechanics/LineOfSight.md).
- Both enemies and allies are affected by this spell.
- Characters will turn according to a fixed pattern (no matter which direction of where from the sram is casting the spell).
