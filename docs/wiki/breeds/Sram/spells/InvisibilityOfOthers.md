# InvisibilityOfOthers

## Invisibility of Others

This buff gives an ally invisibility for 2 rounds.

| Field | Value |
|---|---|
| Class | Sram |
| Cost | 200K |
| AP | 4 |
| Target | Non-Self |
| Range | 1 to 1 |
| Duration | 2 Rounds |
| Recast | No |
| Effect | Invisibility |

**Notes**: Works as the sram spell Invisibility. See that page for more info about invisibility.
