# Fog

## Fog

This spell places an area of fog in which characters are invisible.

| Field | Value |
|---|---|
| Class | Sram |
| Cost | 200K |
| AP | 5 |
| Target | Any |
| Range | 1 to 2 |
| Duration | 2 Rounds |
| Recast | 8 Rounds |
| Effect | Creates a zone of fog |

**Notes**: The fog works equally to both players. Allies are visible and enemies are invisible as long as they stay in the fog.

- Being in the fog follows same rules as Invisibility: you still can take damage, need to make dodge rolls etc.
- You can spot enemies with Perception just like invisibility.
