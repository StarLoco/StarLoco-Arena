# Lethal Trap

This spell places a lethal trap on an empty tile on which any landing character will immediately die.

**Class**: [Sram](../Sram.md)

**Cost**: 300K

**AP**: 6

**Target**: Empty

**Range**: 1 to 1

**Duration**: Game or until used

**Recast**: No

**Effect**: Places a lethal trap

---

**Notes**

* The lethal trap will disappear after it kills one character.
* It is possible to walk over the lethal trap without triggering it. It is not possible to stop on the lethal trap tile while doing this.
* The lethal trap will usually be used in a combination with a sacrier or a panda because it is very hard to set it up and trigger it by the same sram in the same turn. For this purpose it is important to have the sram have just a tiny bit more initiative than the sacrier. If not, the opponent's characters can come after the sram and before the sacrier and thus avoid the trap.
