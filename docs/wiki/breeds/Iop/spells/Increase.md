# Increase

## Increase

This buff increases damage of target ally or self.

| Field | Value |
|---|---|
| Class | Iop |
| Cost | 100K |
| AP | 2 |
| Target | Ally |
| Range | 0 to 1 |
| Duration | 1 Round |
| Recast | Yes |
| Effect | +1 dmg of all elements |

**Notes**: Often seen used together with Bravery Guide to boost a character +5 damage.
