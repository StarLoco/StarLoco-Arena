# Celestial Sword

This is a damage spell which affects an area.

| Field | Value |
|---|---|
| **Class** | Iop |
| **Cost** | 200K |
| **AP** | 4 |
| **Target** | Enemys |
| **Range** | 1 to 3 in Line |
| **Recast** | Yes |
| **Effect** | 8 (Earth) dmg in area |
| **Critical Effect** | 13 (Earth) dmg in area |

**Area**: See original page for diagram.

**Notes**

- Area affected is target tile plus all neighboring tiles. Totally 5 tiles affected.
- It is possible, if the target is close enough that the caster will be hurt from his own spell.
- See the Damage page for a comparison chart of all damage spells.
