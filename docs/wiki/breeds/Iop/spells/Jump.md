# Jump

## Jump

This spell teleports target to any empty tile within range.

| Field | Value |
|---|---|
| Class | Iop |
| Cost | 200K |
| AP | 3 |
| Target | Empty |
| Range | 1 to 2 |
| Recast | 1 per Turn |
| Effect | Teleports caster to target |

**Notes**: Very useful to break out of dodge rolls, get behind enemies, jump over obstacles or simply gain ground.

- Range of the jump is increased by buffing range.
- This spell ignores line of sight.
- It is possible to jump up on roofs with this spell.
