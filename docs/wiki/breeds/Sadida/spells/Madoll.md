# Madoll

This spell summons a madoll.

**Class**: [Sadida](../Sadida.md)

**Cost**: 200K

**AP**: 4

**Target**: Empty

**Range**: 1 to 1

**Recast**: Yes

**Effect**: Summons a madoll

**Madoll stats**

| Stat | Value |
|---|---|
| HP | 10 |
| MP | 3 |
| AP | 6 |
| Spell | Irritation |
| AP Cost | 5 |
| Range | 1 to 3 |
| Recast | Yes |
| Effect | -1 AP |
| Critical Effect | -3 AP, -3 MP |
| Behavior | Hit and Return |

---

**Notes**

* The madoll will if possible move in to range 2 before casting spell even though it really has range 3.
* After casting its spell, the madoll will always try to return to its mother/father sadida, so if you want it to stick to the opponent, make sure that your sadida sticks to the madoll.
* If one AP-boost a madoll to 10 AP it can cast Irritation two times.
* See [this page](../../../rules/Summons.md) for general information about summons.
