# Knowledge of the Dolls

This buff increases the maximum number of summons the caster can handle with one.

**Class**: [Sadida](../Sadida.md)

**Cost**: 100K

**AP**: 3

**Target**: Self

**Duration**: Game

**Recast**: No

**Effect**: Increases number of max summons with one
