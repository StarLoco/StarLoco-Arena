# Dollical Sacrifice

This is a life stealing spell which only can be used against summons.

| Field | Value |
|---|---|
| **Class** | Sadida |
| **Cost** | 200K |
| **AP** | 3 |
| **Target** | Summon |
| **Range** | 1 to 1 |
| **Recast** | Yes |
| **Effect** | Steals 4D6 Earth dmg |

**Notes**
- Only works against summons, though it works both against friendly and hostile summons.
- Works as the sram spell [Life Theft](../../Sram/spells/LifeTheft.md). See page for more information about life stealing.
