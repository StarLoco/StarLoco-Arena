# Eagle Eye

This buff increases the range of target with 1.

| Field | Value |
|---|---|
| **Class** | Cra |
| **Cost** | 200K |
| **AP** | 4 |
| **Target** | Ally |
| **Range** | 0 to 3 |
| **Duration** | Game |
| **Recast** | No |
| **Effect** | +1 range |
| **Critical Effect** | +2 range |

**Notes**
- This spell ignores [line of sight](../../../mechanics/LineOfSight.md).
- When the cra dies, the buff is removed from the target.
