## Frozen Arrow

This is a damage spell which also removes AP and MP from target.

| Field | Value |
|---|---|
| Class | Cra |
| Cost | 150K |
| AP | 3 |
| Target | Enemy |
| Range | 1 to 2 |
| Duration | 1 Round |
| Recast | Yes |
| Effect | 4 (water) dmg, -1 MP, -1 AP |
| Critical Effect | 8 (water) dmg, -2 MP, -2 AP |
