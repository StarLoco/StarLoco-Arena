# Burning Arrow

This is a damage spell which affects an area.

| Field | Value |
|---|---|
| **Class** | Cra |
| **Cost** | 350K |
| **AP** | 7 |
| **Target** | Enemy |
| **Range** | 2 to 5 in Line |
| **Recast** | Yes |
| **Effect** | 16 (Fire) dmg in area |
| **Critical Effect** | 25 (Fire) dmg in area |

**Area**: See original page for diagram.

**Notes**

- Area affected is target tile plus the next two tiles that lies in targeted line. Actual reach of spell is with other words 7.
- It is possible to shoot through trees and other obstacles with this spells.
