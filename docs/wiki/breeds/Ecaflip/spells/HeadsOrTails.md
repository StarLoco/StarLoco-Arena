# HeadsOrTails

## Heads or Tails

This is a damage spell which also heals the target.

| Field | Value |
|---|---|
| Class | Ecaflip |
| Cost | 150K |
| AP | 3 |
| Target | Enemy |
| Range | 1 to 5 |
| Recast | Yes |
| Effect | 2D6 (earth) dmg, heals 1D6 |
| Critical Effect | 2D6 (earth) dmg |

**Notes**: As with All or Nothing, the damage is dealt first and the healing afterwards. If target dies from the damage, no healing is taking place.
