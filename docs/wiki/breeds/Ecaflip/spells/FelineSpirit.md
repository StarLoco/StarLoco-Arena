# FelineSpirit

## Feline Spirit

This is a damage spell which hurts both target and caster.

| Field | Value |
|---|---|
| Class | Ecaflip |
| Cost | 300K |
| AP | 3 |
| Target | Enemy |
| Range | 1 to 1 |
| Recast | Yes |
| Effect | 5D5 (earth) dmg to target, 4D5 (neutral) dmg to self |
| Critical Effect | 5D5+5 (earth) dmg to target, 1D5 (neutral) dmg to self |

**Notes**: One of the strongest damage spells, but will kill yourself. Unbuffed it does in average 30 damage when cast twice. (24 damage to self.)
