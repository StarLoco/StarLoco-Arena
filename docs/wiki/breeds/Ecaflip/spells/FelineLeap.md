# FelineLeap

## Feline Leap

This spell moves caster a single tile.

| Field | Value |
|---|---|
| Class | Ecaflip |
| Cost | 200K |
| AP | 2 |
| Target | Empty |
| Range | 1 to 1 |
| Recast | Yes |
| Effect | Teleports caster to target |

**Notes**: Very useful to break out of dodge rolls as well as converting 2 AP to 1 MP.

- Range of leap is not increased by buffing range.
- It is not possible to leap up on roofs with this spell.
