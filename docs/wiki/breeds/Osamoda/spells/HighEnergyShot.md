# HighEnergyShot

## High Energy Shot

This buff increases the AP of targeted summons.

| Field | Value |
|---|---|
| Class | Osamoda |
| Cost | 100K |
| AP | 3 |
| Target | Summon |
| Range | 1 to 2 |
| Duration | 1 Round |
| Recast | 2 Rounds, Once Each |
| Effect | +6 AP |

**Notes**: Read more about summons on the Summons page.
