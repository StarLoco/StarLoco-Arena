# Carapace

This debuff decreases damage dealt of targeted summons.

| Field | Value |
|---|---|
| **Class** | Osamoda |
| **Cost** | 150K |
| **AP** | 2 |
| **Target** | Summon |
| **Range** | 1 to 2 |
| **Duration** | 1 Round |
| **Recast** | Once Each |
| **Effect** | -5 dmg of all elements |

**Notes**

- This spell does NOT increase the resistance of summons as one is lead to beleive. It should be cast against enemy summons. It works like the feca spell Weakness except it only work against enemy summons.
- Compared to Weakness this spell is quite poor. It only work against summons, has bad range and cost 2 AP compared to Weakness which cost 1 AP.
