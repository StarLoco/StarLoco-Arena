# Bear's Cry

This buff increases damage dealt of targeted summons.

| Field | Value |
|---|---|
| **Class** | Osamoda |
| **Cost** | 100K |
| **AP** | 3 |
| **Target** | Summon |
| **Range** | 1 to 2 |
| **Duration** | 1 Round |
| **Recast** | Once Each |
| **Effect** | +3 dmg of all elements |
| **Critical Effect** | +5 dmg of all elements |
