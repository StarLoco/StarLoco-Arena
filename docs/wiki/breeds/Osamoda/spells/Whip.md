# Whip

This is a damage spell which only can be used against summons.

**Class**: Osamoda
**Cost**: 100K
**AP**: 2
**Target**: Summon
**Range**: 1 to 3
**Recast**: Yes
**Effect**: 20 neutral dmg
**Critical Effect**: 30 neutral dmg

---

**Notes**
- Works as well against friendly as hostile summons.
