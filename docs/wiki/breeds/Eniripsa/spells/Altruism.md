# Altruism

This spell heal all characters: allies and enemies.

| Field | Value |
|---|---|
| **Class** | Eniripsa |
| **Cost** | 200K |
| **AP** | 3 |
| **Target** | All |
| **Recast** | Yes |
| **Effect** | Heals 1D6+3 |
| **Critical Effect** | Heals 10 |

**Notes**

- Casting twice, this spell will heal in average 13 HP to each character. (In practice more, because of critical hits.)
