# HealingWord

## Healing Word

This spell heals any ally except caster.

| Field | Value |
|---|---|
| Class | Eniripsa |
| Cost | 200K |
| AP | 3 |
| Target | Non-Self |
| Range | 1 to 2 |
| Recast | Yes |
| Effect | Heals 8 |
| Critical Effect | Heals 12 |

**Notes**: Probably the most potent healing spell for single targets even though Regenerating Word does heal more overall. The reason it being more potent is that it is very hard to heal someone with very low HP with regeneration. It will probably die before it get to use all heal.

- Healing Word is probably better when you have many characters with base HP while Regenerating Word could be better if you have few characters with extra HP.
- Note that caster can not be the target with this spell.
