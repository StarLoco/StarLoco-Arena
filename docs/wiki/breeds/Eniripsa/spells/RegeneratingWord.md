# Regenerating Word

This spell heals allies over time.

**Class:** Eniripsa

**Cost:** 100K

**AP:** 3

**Target:** Ally

**Range:** 0 to 3

**Duration:** 3 Rounds

**Recast:** Yes

**Effect:** +3 regeneration (heals 3 every round)

---

**Notes**
- Casting twice, this spell will heal totally 18 HP, compared to [Healing Word](./HealingWord.md) which will heal 16 HP.
- If cast twice every turn on same target, it will eventually heal 18 HP every turn.
