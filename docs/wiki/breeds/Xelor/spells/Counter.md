# Counter

This buff makes caster reflect up to 3 incoming damage.

| Field | Value |
|---|---|
| **Class** | Xelor |
| **Cost** | 100K |
| **AP** | 2 |
| **Target** | Self |
| **Duration** | Game |
| **Recast** | No |
| **Effect** | +3 damage reflect |

**Notes**
- This work like [damage rebound](../../../mechanics/DamageRebound.md) except that 3 damage is also absorbed. For example, let's assume somebody hit the xelor with a 10 damage spell. 3 of those is reflected to the caster and 7 damage goes through to the xelor.
