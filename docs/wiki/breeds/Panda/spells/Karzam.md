# Karzam

## Karzam

This spell makes caster pick up an enemy.

| Field | Value |
|---|---|
| Class | Panda |
| Cost | 200K |
| AP | 5 |
| Target | Enemy |
| Range | 1 to 1 |
| Recast | Yes |
| Effect | Picks up character |

**Notes**: Target must be an enemy or a hostile summon.

- See Karcham for special rules about carrying people.
