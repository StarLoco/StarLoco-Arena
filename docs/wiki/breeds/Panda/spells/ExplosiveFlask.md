# Explosive Flask

This is a damage spell which affects an area.

| Field | Value |
|---|---|
| **Class** | Panda |
| **Cost** | 400K |
| **AP** | 5 |
| **Target** | Enemy |
| **Range** | 1 to 4 |
| **Recast** | Yes |
| **Effect** | 8 Fire dmg in area |
| **Critical Effect** | 15 Fire dmg in area |

**Notes**
- It is possible, if the target is close enough that the caster will be hurt from his own spell.
- See [this page](../../../mechanics/Damage.md) for a comparison chart of all damage spells.
