# Chamrak

This spell throws a character which has been picked up.

| Field | Value |
|---|---|
| **Class** | Panda |
| **Cost** | 200K |
| **AP** | 3 |
| **Target** | Empty |
| **Range** | 1 to 4 |
| **Recast** | Yes |
| **Effect** | Throws character |

**Notes**

- Used in conjunction with Karcham or Karzam.
- It is possible to throw characters into traps, or onto rooftops.
