# Teleportation

This spell teleports target to any empty tile within range.

**Class**: Feca, Xelor
**Cost**: 200K
**AP**: 6
**Target**: Empty
**Range**: 1 to 6
**Recast**: No
**Effect**: Teleports caster to target

---

**Notes**
- Target tile need to be in line of sight.
- It is possible to teleport up on roofs.
