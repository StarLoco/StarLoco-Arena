# Earth and Water Armor

This buff gives caster permanent added protection against earth and water spells.

| Field | Value |
|---|---|
| **Class** | Feca |
| **Cost** | 100K |
| **AP** | 3 |
| **Target** | Self |
| **Duration** | Game |
| **Recast** | No |
| **Effect** | +4 Earth dmg red. and +4 Water dmg red. |
