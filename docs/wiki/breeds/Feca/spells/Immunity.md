# Immunity

## Immunity

This spell gives target immunity against most kinds of damage for one turn.

| Field | Value |
|---|---|
| Class | Feca |
| Cost | 100K |
| AP | 3 |
| Target | Ally |
| Range | 0 to 1 |
| Duration | 1 Round |
| Recast | No |
| Effect | +100 dmg red. of all elements |
| Critical Effect | No |

**Notes**: Immunity works as Truce except it is only affecting a single character.

- Immunity does not help against push damage or altitude damage.
- Immunity does not help against lethal traps or the special kill tiles but it does help against spike tiles.
- Immunity does not help against dropping tiles.
- Immunity does not help against Poisoning or Roulette.
- For all other spells, including self-inflicting neutral damage spells, immunity prevent all damage.
- Common use is to cast it on an iop which then can cast multiple Mutilation without taking damage.
- Immunity doesn't prevent healing so some spells are especially useful with immunity: All or Nothing, Word of Sacrifice, Word of Torture, Life Transfer.
- Immunity does prevent life stealing with spells such as Life Theft and Bloodthirsty Madness.
