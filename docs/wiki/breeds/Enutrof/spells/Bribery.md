# Bribery

This spell removes 5 MP of targeted enemy but also healing him up 100 HP.

| Field | Value |
|---|---|
| **Class** | Enutrof |
| **Cost** | 200K |
| **AP** | 6 |
| **Target** | Enemy |
| **Range** | 1 to 6 |
| **Duration** | 1 Round |
| **Recast** | Yes |
| **Effect** | -5 MP, heal 100 HP |

**Notes**

- Can not be used to heal your own characters.
- Typically used to hold certain characters at bay while killing of others first.
- One trick is to use it on an enemy character that stands on a tile about to drop.
