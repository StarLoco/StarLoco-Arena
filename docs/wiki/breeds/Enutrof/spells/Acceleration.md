# Acceleration

This buff increases the MP of target with 1.

| Field | Value |
|---|---|
| **Class** | Enutrof |
| **Cost** | 200K |
| **AP** | 2 |
| **Target** | Non-Self |
| **Range** | 1 to 2 |
| **Duration** | Game |
| **Recast** | No |
| **Effect** | +1 MP |

**Notes**

- It is not possible to cast this spell on yourself.
- When the enutrof dies, the buff is removed from the target.
