# GhostlyShovel

## Ghostly Shovel

This is a damage spell which also dispels all magic effects on critical hits.

| Field | Value |
|---|---|
| Class | Enutrof |
| Cost | 300K |
| AP | 5 |
| Target | Enemy |
| Range | 1 to 5 |
| Recast | Yes |
| Effect | 8 (water) dmg |
| Critical Effect | 15 (water) dmg, dispel magic effects |

**Notes**: On critical hit, all buffs on target will be dispelled.

- See Word of Youth for more info about what can be dispelled.
- See the Damage page for a comparison chart of all damage spells.
