# Target

When casting a spell one has to specify the target of the spell. Different spells have different rules regarding target as noted in the table below:

| Target Type | Description |
|---|---|
| Enemy | Spell is typically used to hurt enemy. Example: Bubble |
| Ally | Spell can be cast on any ally. Example: Regenerating Word |
| Empty | Spell is cast on empty tile. Example: Teleportation |
| Self | Spell can only be cast on yourself. Example: Invisibility |
| Non-Self | Spell can be cast on any ally except yourself. Example: Acceleration |
| Summon | Spell can only be cast on summons. Example: Whip |
| Any | Spell is used both on allies and enemies. Some spells can also be cast on empty ground. Example: Fear |
| All | Spell affect all characters in game, allies and enemies. Example: All or Nothing |

Note that:

- In some cases characters not targeted can still be affected by the spell.
- It is often possible to target a spell on an empty tile, possibly wasting the action points.
- It is often possible to use a hostile spell on a friendly unit and vice versa.
