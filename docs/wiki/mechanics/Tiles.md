# Special Tiles

A character standing on a special tile on the beginning of his turn grants a special effect accourding to the table below:

| Tile | Effect |
|---|---|
| Killer tile | Character dies if he begins the turn on this tile. If he ends his turn on this tile or gets placed here, it is still possible to survive if someone removes him/her from the tile before his next turn. |
| Trap tile | Character takes 10 HP of neutral damage. |
| Enthusiasm tile | Character gets a +5 neutral damage bonus for that turn. See the Damage page (Motivation damage section) to see which spells are affected. |
| Shield tile | Character gets a +1 damage reduction bonus for that turn. Does not work in Beta 13 (damage reduction ends as soon as the character's turn ends). |
| Eagle eye tile | Character gets a +1 range bonus for that turn. |
| Panacea tile | Character gets a +5 bonus to healing. Usually only useful for an eniripsa but an ecaflip with heads or tails will be surprised if he begins his turn on this field. |
| Motivation tile | Character gets a +2 AP bonus for that turn. |
| Healing heart tile | Character is healed 5 HP. |
