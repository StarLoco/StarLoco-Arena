# Action Points

Action Points (AP) denotes how many actions a character can make per turn. Each action have a certain AP cost. Each character have as default 6 action points, but this number can be altered by items, spells, special tiles, bonus-, and event-cards.

The actions that can be made are as following:

- Casting spells
- Using weapons
- Using fists

Not used action points are effectivly lost for that round.
