# Movement Points

_Movement Points_ (MP) denotes how many tiles a character can move per turn. Each horizontal or vertical step cost 1 MP. Each character have as default 3 movement points, but this number can be altered by [items](../items/Items.md), [spells](../rules/Spells.md), [bonus](../rules/BonusCards.md)-, and [event](../rules/EventCards.md)-cards.

**Items that affect MP**

| Item | Cost | Bonus |
|---|---|---|
| Bow Meow | 350K | +1 MP, +30 initiative |
| Moon | 600K | +1 MP, +1 range, +60 initiative |
| Rags | 350K | +1 MP |
| Dofus Vulbis | 350K | +1 MP |
