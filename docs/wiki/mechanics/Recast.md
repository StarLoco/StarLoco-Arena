# Recast

Denotes how often a [spell](../rules/Spells.md) can be cast as noted in table below:

| Value | Meaning |
|---|---|
| Yes | Spell can be cast unlimited times, limited only by [AP](./ActionPoints.md). |
| No | Spell can only be cast once per game. |
| Once Each | Spell can only be cast once for each [target](./Target.md) each turn. |
| X Rounds | Spell cannot be cast the next X rounds after it has been cast. |
