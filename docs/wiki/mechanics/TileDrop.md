# Dropping Tiles

At the end of turn 15, tiles of the map start to drop to ensure victory for one of the players. A dropped tile and anything on it is removed from the game and the board get successively smaller for each round. Exactly how the tiles drop are individual for each map, but generally each four edge rows are dropped each turn. Note that the tiles are dropped one by one when they are dropping, so if all characters are standing on tiles that will be dropped, the last one will be in the winning team. It can be a good idea to learn which tile will be the last one to drop for different maps.

Some nice tricks:

- Trap a character out on the edge by moving close by, forcing him to make a dodge roll.
- Throw, or push a character that has already moved this turn out to the edge to a tile that will be dropped.
- If tiles haven't start dropping yet, why not use Bribery to keep him there until they do?
- Go to the edge and assault an opponent that has already moved. Assault is a great spell to have in the endgame.
- If you need to trap a sram with Fear out to the edge, use two characters so that fearing will cause both to hurt but none to move. In this way he is forced to make a dodge roll.

Note that if a panda holds a character, the panda will be considered dying before the one it is holding.
