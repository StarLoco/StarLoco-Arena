# 2 vs 2

Dofus arena can be played in 2 vs 2 mode. This work as 1 vs 1 with the following differences:

- Each team has 6000 kamas totally. Each of the two players in one team get 3000 kamas.
- Each team has two team leaders, one for each player in the team.
- Each player get X cards.
- Each player can only control his own half of the team.
- Both players in a winning team get ladder XP even if one of the two was dead before game ended.

All game mechanics are otherwise the same. You can see your own invisible team-members etc. The game is ended when both players in one team are defeated.
