# Team

Each player have one team which consist of one or several (maximum six) characters. Each team can have a value of up to 5000 kamas in the case of 1 vs 1 mode or 3000 in the case of 2 vs 2. Each team must designate one and exactly one of his characters to be a team-leader before any game starts. The only additonal function a team-leader has compared to the other characters, is that the team-leader is the only one able to use bonus cards. In all other aspects, the team-leader works as a normal character.
