# Characters

Each player can have up to 10 different characters of any class at any time. From these, one choose which ones to participate in the fight before the fight starts. One may have at most 6 characters participating. If a character takes a lethal blow or if one choose to remove a character, a new character can be made but all earned XP for that character are lost. However in the latest verison of Dofus Arena, this is not a problem since the characters don't get any XP or skills. A lethal blow has no other significance other than the annoyance to recreate the character.

Each character has a base cost of 400 kamas independent of class, but if one put multiple characters of the _same_ class into the same fight, one have to pay an additional cost accourding to the table below:

| Amount of characters of same class | Total extra cost |
|---|---|
| 1 | +0k |
| 2 | +0k |
| 3 | +200k |
| 4 | +500k |
| 5 | +900k |
| 6 | +1400k |

Each character have the following properties:

- Appearance (Name, Sex and Color)
- Class
- Health Points (HP)
- Action Points (AP)
- Movement Points (MP)
- Initiative (Init.)
- Items
- Spells
