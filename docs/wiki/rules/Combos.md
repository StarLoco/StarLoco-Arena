# Combos

Combos are enhanced versions of spells, executed by placing characters in a geometrical pattern and having them cast the spell [Charge](../mechanics/Charge.md). The one character performing the combo should be part of the pattern but he should not cast the charge spell, rather he should cast the one spell we want enhanced.

There are five different geometrical patterns: 3-Line, 4-Line, Triangle, Square, and Cross.

**Notes**
- It doesn't matter where in the pattern the character performing the combo is positioned.
- It doesn't matter if there are other characters in between the charging characters.
- When casting a charged spell, symbols will appear above all charging characters. Thus it is easy to see if the setup was correct.
- When cast an enhanced spell, the charges used is spent.
- See [this page](../mechanics/Charge.md) for more information about the charging spell.
- Line patterns can not be diagonal in any way.
- Larger versions of the patterns are also valid.
- Charged spells does not [crit](../mechanics/CriticalHits.md). _(Confirm)_
- Enhanced [Life Theft](../breeds/Sram/spells/LifeTheft.md) is bugged. Immobilization lasts 0 rounds.
